# Support

For installation, see [Install and test EmberCast](docs/INSTALL.md). For known test limits, see [validation notes](docs/VALIDATION.md). For build, device test, and release steps, see [development procedures](docs/PROCEDURES.md).

When reporting a problem, include the app version, Fire TV model and Fire OS version, Android API level, sender device, whether both devices use the same network, and the exact steps to reproduce it. Remove home network addresses, account details, screenshots of private content, and personal recordings before sharing logs.

Open a [GitHub issue](https://github.com/mmorrone90/firemirror/issues) for reproducible bugs or feature requests. For a suspected security issue, use the private reporting instructions in [SECURITY.md](SECURITY.md).
